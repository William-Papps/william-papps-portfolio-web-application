# William Papps Personal Portfolio

This is A personal portfolio webpage built with HTML and CSS.
This was built as part of my web development coursework at Nelson Marlborough Institute of Technology.

This website is designed to introduce myself as Bachelor of Information Technology Student and showcase some of my projects and skills I've learnt inside and outside of school aswell as my interests.

Pages:

- Home: A small introduction style page showcasing some of my most important information.
- About: In depth information about myself such as background, education and interests.
- Projects: A professional view of the project's I've worked on, with screenshots and links.
- Skills: A page to display my technical skills and tools I've learnt.
- Contact: My contact details and a form layout.

This website was built with the following services and tools:

- HTML
- CSS
- node.js

- Github

How to open

1. Download and/or clone the GitHub Repository
2. Open the project folder inside of Visual Studio Code or another IDE
3. Install Live-Server extension for Visual Studio Code
4. Right-Click home.html and click open live server

This version is strictly only for HTML and CSS so some aspect's aren't implemented yet such as the contact form aswell as the menu for the mobile view navigation.

To change page on mobile view you have 2 options.

- Open live server on the page you wish to see
- Change the URL of the live server from home.html to another page's link such as skills.html
